# Licence of the data StudyHelp publishes

StudyHelp draws on open sources with different licences, and what it publishes
inherits the strictest of them.

## The published site data is CC BY-SA 4.0

The word-level links between the Greek New Testament and its lemmas derive from
the **MorphGNT** morphological tagging, which is licensed **CC BY-SA 3.0**. A
share-alike licence propagates: anything built from it must be released under the
same licence or a later compatible one. So the generated data this site serves —
`index.json`, `terms.json`, the per-word and per-chapter files — is published
under **CC BY-SA 4.0**, which CC lists as compatible with BY-SA 3.0.

The source code is separate and carries its own licence.

## What each source requires

| Source | Licence | What it obliges |
| --- | --- | --- |
| MorphGNT tagging | CC BY-SA 3.0 | Attribution **and** share-alike on derivatives |
| SBLGNT base text | SBLGNT EULA | See the open question below |
| MACULA Greek and Hebrew | CC BY 4.0 | Attribution |
| OpenScriptures (OSHB, Strong's, BDB) | CC BY 4.0 / public domain | Attribution for the markup |
| Cherith glosses | CC BY 4.0 | Attribution |
| Berean Standard Bible and Interlinear | Public domain | None |
| Abbott-Smith, BDB, historical translations | Public domain | None |
| Swete Septuagint | GPL-3.0 packaging over a public-domain text | Attribution |
| Perseus LSJ | CC BY-SA | Registered, not used |

Every source is credited on the site, generated from the registry rather than
maintained by hand, and grouped by whether it is a primary witness, a
translation, an aggregator's repackaging, or reference data.

## Two constraints worth stating plainly

**The King James Version is under Crown copyright in the United Kingdom.** It is
public domain almost everywhere else, but within the UK the rights are held by
the Crown under letters patent and administered by Cambridge University Press.
This site does not geo-restrict it; the constraint is disclosed instead, and the
KJV carries that notice wherever it is credited.

**The SBLGNT base text sits under its own EULA**, separate from the CC BY-SA
tagging. That EULA could not be retrieved from the environment this project was
built in, so its terms have not been confirmed. See BACKLOG.md for the open
question and the alternative that was evaluated.
